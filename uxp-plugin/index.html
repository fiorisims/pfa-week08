How it works

In a color script template, click a panel thumbnail (or select a panel layer) and pick a mood. Each click makes a new palette and clicking the same panel's overlay rerolls it. With "Whole row, slight variations" ticked, the mood covers every panel in that row with a gentle left-to-right hue drift, all in one undo step. Strength adjusts the whole row while row mode is on. Import grayscale images opens a multi-select file picker and waits for a mood: that click adds the same gradient map (one palette) to every imported image. Pick another mood to reroll them all. Without a template or import, a mood tints the active document. With Gradient map checked a grayscale image is replaced by that ramp, otherwise a non-destructive Color layer tints it. Drag Strength to adjust, or Clear to remove.
